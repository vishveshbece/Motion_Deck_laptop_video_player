## Silicon Labs AI-SDK usage instructions
Silicon Labs AI-SDK is a collection of MCP tools, Agent Skills, and project-aware context for embedded software development. It provides an end-to-end framework for AI agents for understanding projects, answering Silicon Labs–specific questions, debugging, code generation, and iterative feature development.

For any task involving Silicon Labs products, SDKs, tooling, documentation, or project-specific workflows, use Silicon Labs Agent Skills and MCP tools before relying on model knowledge, handwritten code, or shell commands.

Never modify the contents of the autogen directory directly, as those changes may be overwritten when the project is regenerated.

**Never** delete a project or workspace folder. Even when struggling with using a tool, deleting an entire project or workspace is absolutely *never* an acceptable solution.

### Required execution order for every Silicon Labs task
1. Check whether a suitable Agent Skill exists.
2. If one or more suitable Agent Skills exist, use the most appropriate one.
3. Otherwise, check whether an MCP tool can perform the task.
4. If one or more suitable MCP tools exist, use the most appropriate one.
5. Only if neither is available, use shell commands or handwritten code.
6. Explain why manual work was necessary.

### Silicon Labs Knowledgebase
The AI-SDK includes a RAG knowledge base with Silicon Labs documentation and other relevant knowledge.

For every task involving *Silicon Labs specific* information, you MUST query the available Silicon Labs knowledge-base MCP tools first, before answering, using local search, or making changes. Do not substitute workspace search for the knowledge base. Use local search only as a follow-up when the knowledge-base results identify files or when workspace-specific content is required.
